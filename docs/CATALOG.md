# The Catalog

The Catalog is the list of public threat feeds ThreatCull knows how to fetch, each with its licence,
whether a business may use it, and whether a new install turns it on. It ships with every release
in [`src/threatcull/catalog.yaml`](../src/threatcull/catalog.yaml). Your own lists are custom
Sources and are not part of the Catalog.

ThreatCull downloads each Source straight from its publisher, so the publisher's terms apply to
you. The licence labels summarise those terms. They are not legal advice: open the licence link
before you rely on a Source.

## Keeping it up to date

New Sources and corrections reach you between releases:

- **Web UI:** Sources page, **Catalog** card, **Check for updates**.
- **CLI:** `threatcull catalog update`, and `threatcull catalog show` for the revision in use.
- **No internet access:** upload a newer `catalog.yaml` on the same card, or run
  `threatcull catalog update --file catalog.yaml`.

An update adds new Sources **disabled**, refreshes the details of existing ones and disables
Sources the Catalog no longer lists. ThreatCull keeps the update across restarts and uses whichever
Catalog has the higher revision: the saved update or the one in a newer release.

### Licence classes

| Class | Meaning |
|---|---|
| permissive | Free to use and share, for example CC0 or MIT. |
| copyleft | Free to use; sharing the list on requires the same licence, for example GPL. |
| noncommercial | Personal and other non-commercial use only. |
| restricted | Extra conditions apply. ThreatCull asks you to acknowledge them before you enable it. |
| unknown | The publisher states no clear licence. |

**Business use** says whether a business may use the Source to protect its own network: `allowed`,
`forbidden` or `unknown`. A blocklist that a new install turns on is always `allowed`.

## Future additions

### Suggest a Source

Open an issue with the
[Add a Source to the Catalog](https://github.com/spydisec/threatcull/issues/new?template=source_request.yml)
form. [Open requests](https://github.com/spydisec/threatcull/issues?q=is%3Aopen+label%3Acatalog)
carry the `catalog` label.

A Source joins the Catalog when it has:

- **Published terms:** a licence or terms of use on the publisher's own site, with a link.
- **A stable `https://` URL** in a format ThreatCull reads: `plain`, `hosts`, `adblock`, `csv` or
  `json`.
- **Active maintenance:** updated at least weekly, with a way to report false positives.
- **New coverage:** not a copy of a Source already listed. Lists from the same upstream share a
  family and count once in the confidence score.

### Wanted

The Catalog is thin in these areas. Suggestions with published terms are welcome:

- **Scanners:** mass-scanning and brute-force source IPs (no Source yet).
- **C2 domains:** command-and-control domains (the C2 Sources cover IPs only).
- **IPv6:** blocklists with IPv6 addresses.

### Adding one yourself

1. Add the entry to `src/threatcull/catalog.yaml` with its licence evidence.
2. Raise `revision` by one, so installs pick the change up with **Check for updates**.
3. Run `make catalog-docs` to refresh the tables on this page.
4. Add a line under `## [Unreleased]` in [CHANGELOG.md](../CHANGELOG.md).
